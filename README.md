# CROWN-2510 — BaiYuchen Royal Hub

A mobile-first personal hub built with HTML, CSS and vanilla JavaScript.

## Features
- Royal red, black and gold dashboard
- Notes saved in the current browser on this device
- Learning checklist
- Creative idea list saved locally
- Basic offline cache using a service worker

## Run
Open `index.html` in a browser, or publish the repository using GitHub Pages over HTTPS. Service workers and install prompts require a secure context such as HTTPS.

## GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the deployment to finish. The site URL will be shown in the Pages settings.

Notes and creative ideas are stored in this browser's local storage. They are not synced to GitHub or other devices.
